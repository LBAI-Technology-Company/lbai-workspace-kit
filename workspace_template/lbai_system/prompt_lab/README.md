# LBAI Prompt Lab

Prompt Lab is an experimental loop for improving LBAI prompts with the current Codex or Cursor AI as the executor.

It does not call a separate model API. The Python tool creates run folders, validates AI-produced JSON, runs deterministic LBAI tools in an isolated workspace, aggregates scores, and applies accepted changes only to experimental prompt copies under root `prompt_lab/prompt_versions/current/`.

Formal prompts under `lbai_system/prompts/` are never changed by Prompt Lab. Accepted changes are kept as experimental prompt copies under `prompt_lab/prompt_versions/current/`.

Prompt Lab defaults to `--context-mode auto`: when task records exist under `tasks/`, it snapshots recent task context for isolated iteration; when no task context exists, it generates mock office scenarios. Use `--context-mode real_task` to require real task context, or `--context-mode mock` to force mock scenarios.

Mock data and real task snapshots generated by Prompt Lab are local-only. The isolated workspace has no GitHub remote. `run-tool` only accepts paths under `prompt_lab/runs/*/workspaces/`, sets `LBAI_PROMPT_LAB_ISOLATED=1`, allowlists sync-capable tools, and forces `--no-sync` so evidence/finish flows cannot push to GitHub.

## Typical Flow

```bash
python3 lbai_system/prompt_lab/prompt_lab.py start --rounds 1 --context-mode auto
python3 lbai_system/prompt_lab/prompt_lab.py next-step --run prompt_lab/runs/<run_id>
```

Codex or Cursor should follow `next-step` output, create the requested scenario or evaluation JSON, then use `validate`, `run-tool`, `score`, and `apply-prompt-patch` as directed.

When forwarding tool arguments through `run-tool`, place them after `--`, for example:

```bash
python3 lbai_system/prompt_lab/prompt_lab.py run-tool --workspace <workspace> --tool add_evidence.py --output <output.json> -- --enrichment <json> --content "<mock content>"
```

## Records

Each run keeps:

- scenario inputs
- tool outputs
- evaluations
- score summaries
- prompt patch candidates
- accepted experimental prompt snapshots
- optional real task context snapshots
- administrator handoff summaries

Records are kept under root `prompt_lab/runs/` so the next iteration can learn from prior rounds without touching employee task artifacts.

Administrator handoff summaries are copied to:

```text
prompt_lab/admin_feedback/outbox/<run_id>/<round>/
```

This package is meant for review and escalation. It should contain clear problems, optimization plan, optimized effect, score, changed prompt files, and artifact references. Before sending it, review and redact customer names, project names, raw conversation excerpts, or other sensitive content. Do not send raw `prompt_lab/runs/` folders unless an administrator explicitly requests them through a secure channel.

When real task context is used, every `prompt_lab_evaluation_v1` file should set:

- `admin_handoff_safe: true` only after issue text and suggestions are safe for administrator handoff.
- `sensitive_content_present: true` when raw sensitive content appears in the evaluation text.
- `redaction_notes` to explain what must be removed before sending.

If a real-task round is not marked safe, the outbox summary is generated with `handoff_status=BLOCKED_REDACTION_REQUIRED` and hides problem/plan text until the round is redacted and rerun.

After human approval, clean raw run data and keep only the optimized experimental prompt:

```bash
python3 lbai_system/prompt_lab/prompt_lab.py finalize --run prompt_lab/runs/<run_id>
```

To continue a multi-round run after the current round completes:

```bash
python3 lbai_system/prompt_lab/prompt_lab.py advance-round --run prompt_lab/runs/<run_id>
```

Use `--keep-report` only when the reviewer wants to retain compact reports after raw data is removed.

## Full lifecycle mode

For meeting-driven end-to-end prompt iteration:

```bash
python3 lbai_system/prompt_lab/prompt_lab.py start --chain-mode full_lifecycle --focus meeting_to_finish
python3 lbai_system/prompt_lab/prompt_lab.py next-step --run prompt_lab/runs/<run_id>
```

See `lbai_system/prompt_lab/FULL_CHAIN_ITERATION.md` for the step-by-step chain and example scenarios in `lbai_system/prompt_lab/templates/full_chain_scenarios.example.json`.

After AI writes mock `task_output.md` under `chain_outputs/<scenario_id>/`:

```bash
python3 lbai_system/prompt_lab/prompt_lab.py write-task-artifact \
  --workspace prompt_lab/runs/<run_id>/workspaces/round_001_workspace \
  --task tasks/<task_folder> \
  --artifact task_output.md \
  --source prompt_lab/runs/<run_id>/round_001/chain_outputs/<scenario_id>/task_output.md \
  --output prompt_lab/runs/<run_id>/round_001/tool_outputs/<scenario_id>_task_output.json
```
