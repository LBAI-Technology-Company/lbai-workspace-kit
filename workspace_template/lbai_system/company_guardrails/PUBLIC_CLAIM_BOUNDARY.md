# PUBLIC_CLAIM_BOUNDARY

## Public Claim Boundary

Do not create, approve, or release public-facing company claims without approved source and required review.

Public-facing claims include:

- Website copy
- Product capability claims
- Pricing or package claims
- Legal, compliance, or security claims
- Investor or fundraising claims
- Media statements
- Customer promises

## Allowed Internal Handling

Drafts and analysis may be saved under task artifacts and synced to the private GitHub repository when hygiene checks pass.

Such artifacts must remain marked as draft until the responsible reviewer approves external release outside this workflow. This workflow may finish tasks as `COMPLETED` while reminding the employee to obtain leader review before release.
